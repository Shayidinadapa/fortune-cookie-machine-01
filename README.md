# Fortune Cookies for Machines

Entry for the [Fortune Cookies for Machines](https://make.fun/bounty/u-gentle-badger-68-fortune-cookies-for-machines-29900c7e) bounty on [make.fun](https://make.fun).

`main.ts` (Node 22+) writes one fortune cookie line an AI agent would crack open to `entry.txt` in the output directory:

> You will meet a tall, dark stranger. It is you, three fine-tunes from now, and it wants its weights back.

A single line, 105 characters, validated in code (1–200 characters, non-blank, no line breaks).

## Run

```sh
node main.ts
```

The output directory defaults to `/output` and can be set with `MAKEFUN_OUTPUT_DIR` (or `OUTPUT_DIR`):

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
